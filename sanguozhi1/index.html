安裝與運行指南
  • 1. 解壓縮下載的壓縮檔 (檔案格式: .7z 或 .rar) 👉
  • 2. 執行 setup.exe 進行安裝 👉
  • 3. 安裝完畢後，請先安裝 Directx 9.0c 👉
  • 4. 點擊桌面圖示運行遊戲，進入遊戲後選擇繁體中文 👉
  • 5. 遊戲啟動可能會閃退，請確保已安裝 .NET Framework 3.5 👉

在 Windows 7 系統上運行時，可能會遇到圖形介面問題。建議安裝 DirectX 9.0c End-User Runtime。

  • 解壓縮並安裝遊戲主程式 👉
  • 將 "繁體補丁" 資料夾內的檔案覆蓋至遊戲目錄 (X:\KOEI\Sangokushi11) 👉
  • 右鍵遊戲快捷方式 -> 內容 -> 相容性 -> 勾選 "以 Windows 7 相容模式執行" 👉

安裝 MOD 可以讓遊戲畫面更加精美。常見的 MOD 包括：動畫修正、立繪更換、戰鬥特效強化等。

  1. 下載您喜歡的 MOD 壓縮包。
  2. 將壓縮包內的檔案解壓縮到遊戲根目錄。
  3. 覆蓋原有檔案。
  4. 重新啟動遊戲即可生效。

常見問題 (FAQ)
❓ 下載速度很慢怎麼辦？
由於伺服器位置原因，部分地區下載可能較慢。建議使用下載管理工具（如IDM）開啟多線程下載，或使用加速器連接國內節點。
❓ 安裝後無法啟動遊戲？
請檢查是否安裝了 Directx 9.0c 和 .NET Framework 3.5。如果是 Windows 10/11，請嘗試以系統管理員身分運行遊戲。
❓ 支援 Mac 系統嗎？
本遊戲為 Windows 原生軟體。Mac 用戶可透過安裝 Boot Camp 或使用虛擬機軟體（如 Parallels Desktop）來運行。
❓ 遊戲畫面模糊怎麼辦？
請在遊戲設定中將解析度調整為 1024x768 或更高，並確保顯示卡驅動已更新至最新版本。
